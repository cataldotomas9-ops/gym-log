# Gym Log

App personal para registrar entrenamiento, comidas y medidas, con rutina y guía de técnica. Funciona sin internet una vez instalada en la pantalla de inicio.

Los datos se guardan solo en el navegador del celu.

Fotos de ejercicios: free-exercise-db (https://github.com/yuhonas/free-exercise-db), publicadas como dominio público (Unlicense).
